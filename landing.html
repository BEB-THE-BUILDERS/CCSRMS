Common questions

Quick answers before you log in.

Who can use CCSRMS?

The admin or department head and the program chairs manage schedules with accounts given by the CCS department. CCS students can view the room schedules.

Can a program chair edit other programs?

No. Program chairs only have access to their own program (BSCS, BSIT, BSEMC-DAT, or BSEMC-GD).

Which rooms are in the system?

Only the rooms assigned to the College of Computer Studies.

I forgot my password.

Use the Forgot password link on the login page.

Does it work on my phone?

Yes. Open it in your browser, or install it as an app from the button on this page when it appears.
